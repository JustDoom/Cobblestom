# Cobblestom

Cobblestom is an attempt to "port" the [Cobblemon](https://cobblemon.com) mod over to a [Minestom](https://minestom.net/) library for servers to use.

It would allow Minestom level customisability for server creation with support for Cobblemon. It could also be ported to a Plugin based server such as PaperMC or PurpurMC.

Very basic showcase on Minestom
https://www.youtube.com/watch?v=xqYqRYz0gPA

Discord: https://discord.gg/ydGK5jYV6t

## Setup

Should just work. Run from the Main method in the Main class.

Based on the 1.6.1 version of Cobblemon for Minecraft 1.21.1.

If using their branch to modify the client and test, you may need to change the `fabric-permissions-api` option in `gradle/libs.versions.toml` to `0.3.1` from `0.2-SNAPSHOT`.
