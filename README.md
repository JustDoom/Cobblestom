# Cobblestom

Cobblestom is an attempt to "port" the [Cobblemon](https://cobblemon.com) mod over to a [Minestom](https://minestom.net/) library for servers to use.

It would allow Minestom level customisability for server creation with support for Cobblemon. It could also be ported to a Plugin based server such as PaperMC or PurpurMC.
